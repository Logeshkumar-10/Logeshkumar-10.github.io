How I use AI to get more done, and get it right

I treat AI as a way to cut the repetitive work in analytics delivery, not to skip the thinking. The pattern is the same whatever the task.

1 · Brief

Give it the context, not just the task

I write down the audience, the rules and what done looks like before I start, so the first result is close.

2 · Build

Turn repeated work into reusable tools

If I do a task more than twice, I package it as a Claude skill or a script, so the next run takes minutes.

3 · Verify

Make the output prove itself

Automated checks, reconciliations and documentation look-ups run on every result, so errors show up before I review.

4 · Decide

Keep the judgement human

I review what the checks cannot judge: whether it answers the real business question. Then I sign it off.
